# 更新日志

## v0.0.8（2026-08-15，用户系统）

### 与 v0.0.7 的主要不同

**1. 新增用户系统**
- **用户页**：点击左栏自己的头像，或任意位置其他用户的头像，进入对应用户页；展示头像、昵称、等级、UID、粉丝/文章/评论数（本人页额外显示关注数）、个人介绍、主页背景图，缺失时优雅降级。
- **用户页主页与子页**：主页展示 收藏（仅本人）/ 文章 / 评审 / 评论 各最新 4 条，空栏目自动隐藏；左栏子页为 动态 / 收藏 / 粉丝 / 文章 / 评审 / 评论（他人页无动态与收藏）。头部统计（文章 / 评论 / 粉丝 / 关注）可点击直达对应子页。
- **动态**：聚合展示关注用户最新发表的文章 / 评审 / 评论 / 评审评论，支持分类筛选；文章沿用文章卡样式，评审/评论复用推荐首页信息流卡。
- **左栏用户卡改造**：移除原「退出」按钮，原位置改为「签到」按钮，签到成功后消失并显示能量币余额；用户卡下方小字展示个人介绍；左栏折叠后签到 / 能量币 / 介绍隐藏。
- **头像入口全打通**：文章卡作者、文章页作者行、评审卡、评论卡、首页最新评审/讨论头像均可点击进入用户页；匿名用户头像不可点。
- **登录态启动页**：已登录用户启动应用时直接进入本人用户页，不再停留在推荐页。

**2. 统一落实荒启投稿/评稿期匿名与评分规则**
- 进行中 / 评审中活动的文章与评审，在**所有位置**（文章列表、详情、用户页主页与子页、收藏、动态、推荐首页）都不展示评分与排名；作者展示名统一显示为「匿名用户」。
- 服务端占位评论「活动期间，作者评论回复暂时隐藏」直接隐藏，不再展示。
- 规则收口到主进程 `activity-rules.ts`，渲染层不再散打补丁；收藏文章通过 cid 回查补标；评论列表补全所属文章匿名/作者信息（TTL 缓存 + 并发限制）。

**3. 其他改进**
- 推荐首页与用户页的评审 / 评论卡片统一为共享组件，评分靠右对齐。
- 用户页全量列表改为懒加载哨兵（同作品库列表）；评论分页改用 `nextPage / hasMore` 游标，配合脱敏补拉不重不漏。
- 新增用户接口适配层与 IPC 白名单：资料 / 统计 / 关注 / 粉丝 / 收藏 / 签到 / 动态聚合；私聊仅做按钮占位。

### 验收
- `npm run typecheck` / `npm run build` 通过；GUI 运行与真实账号验证需正常桌面环境（沙箱限制，见 README 验证清单）

## v0.0.7（2026-08-15）

### 变更
- **启动时校验 token 有效性（主进程）**：每次应用启动时检查一次持久化 token——服务端确认失效（`markList` 探测被 `@LoginRequired` 拦截）则立即丢弃本地会话（`clearSession`），应用退回未登录状态；网络异常/离线不误清（可继续本地写作）；校验与窗口创建并行执行、不阻塞启动，渲染层启动恢复仍保留原有校验兜底
- **首启协议门（安装流程内同意本应用用户协议）**：首次启动（或协议版本更新）后、进入应用前，必须先阅读并勾选同意《黄芪饮片用户协议》才能进入——协议全文展示在首启全屏页，**滚动到底部才解锁勾选**，勾选后点「同意并进入」；同意状态与登录页共用同一 localStorage 键（`hqsf-agreement-version`），首启同意后登录时该协议复选框自动勾选、登录时勾选过则首启自动放行；协议文件缺失/读取失败时无法同意（提供重试），保证「同意」始终建立在已展示协议全文之上；**荒启平台协议不进入首启门**（其仍按原样在登录流程中另行勾选）
- **修复顶层评论发布必败**：`commentsAdd` 请求按定制版服务端契约补齐 `parent`/`reviewid` 参数（顶层评论恒写 0）——此前缺 `parent` 时服务端抛「接口请求异常，请联系管理员」；会话有效性探测同步从 `isMark`（探测用 cid=0 恒失败）换成 `markList`，并区分「服务端明确拒绝」与「网络异常」，避免 token 失效时用户停留在已登录界面但操作全报错

## v0.0.6（2026-08-14）

### 变更
- **左栏同步按钮图标改为「云端下载」语义**：原 `RefreshCw`（刷新）与"从云上下载"的实际语义不符，改用 `CloudDownload`（云 + 向下箭头，lucide-react）；tooltip 同步改为「从云端下载草稿与状态」，拉取中旋转动画保留
- **远端文章「编辑 / 转存为草稿」（写作闭环补充）**：① 写作→草稿——无本地文件的远端草稿按文章处理（阅读视图可读），文章页提供「编辑」按钮，点击自动同步全文到本地存档并在本地编辑；② 待审核/已发布/已拒绝文章页提供「转存为草稿」（服务端 `contentsUpdate isDraft=1` 处理）与「编辑」按钮——编辑先等待服务端转存为草稿，再同步全文到本地存档并打开编辑器；③ 阅读详情拉取改 POST 编辑形态优先（作者可读自己的草稿完整正文）、GET 阅读形态回退，本人文章豁免未公开（isopen=0）校验；④ 同步按钮本就全量拉取四态到本地（无本地文件的待审核/已发布/已拒绝也会落盘，无需改动）

- **取消「必须登录才能看到内容」**：未登录也能直接进入主界面——写本地草稿、浏览文章列表/栏目、阅读公开文章均可用，不再被登录页挡住；登录改为覆盖层模态（左栏用户卡显示「未登录 · 点击登录」唤起，可「先逛逛」关闭），登录成功自动收起并重拉评审任务
