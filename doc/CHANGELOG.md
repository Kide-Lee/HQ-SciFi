# 更新日志

## v0.0.4（开发中，未发布）

### 新增

- **图标系统**：引入 [lucide-react](https://lucide.dev/)（v1.30，**ISC 许可**，与项目 MIT 兼容：允许商用/修改、无署名义务；官方支持 React 19；纯本地 SVG 组件 + tree-shaking，适配离线渲染层），统一替换界面 emoji/unicode 符号
  - 覆盖：阅读页互动条（投币 `Coins` / 点赞 `ThumbsUp` / 收藏 `Bookmark` / 分享 `Share2`）、评审按钮 `PenLine`、返回列表 `ArrowLeft`、目录与树节点展开箭头 `ChevronRight`、同步 `RefreshCw`、设置 `Settings`、排序方向 `ArrowUp/ArrowDown`、关闭/提示 `X`

## v0.0.3（2026-08-08）

本版本是 v0.0.2 样式改进的完整交付：排序、栏目首页、活动树、评审栏体验全面升级，并修复 Windows 版无法打开界面的问题。

### 新增

- **栏目首页**：点击左栏「推荐 / 连载 / 活动 / 作品库」顶层时显示对应首页
  - 推荐：置顶文章区 + 最新发布流（仿荒启 h5 首页）
  - 连载：「推荐合集」「推荐连载」两个栏目，卡片带封面，每组限制展示前 8 个
  - 活动：近期活动列表，卡片带封面 + 状态徽章 + 两行统计
  - 作品库：四个作品分类入口 + 最新发布流
  - 所有首页加载时显示预填充骨架（宽度填满页面，加载后无抖动）
- **活动树**（左栏活动栏目）
  - 活动按钮右侧红点：未完成评审任务数
  - 活动节点可展开，子项为该活动文章（按标题排序、懒加载）
  - 正在阅读的文章在树中高亮；待评审 / 已评审文章带徽章
  - 「进行中」「评审中」活动带状态标记；这两类活动的文章不进入评分榜、不显示评分与排名
- **文章归属标签**：阅读页显示文章所属的「活动 / 分类 / 合集」标签，点击跳转到对应栏目列表，并自动定位左栏
- **评审栏增强**
  - 「我的评审 / 所有评审」双视图：未评审时直接评审；已评审可随时进入编辑模式，提供「退回展示」按钮
  - 评审时实时显示五维评分平均分预示；编辑框随内容自动增高、不显示滚动条、不可手动调高
  - 所有评审支持按 时间 / 评分 / 开心 / 有用 / 认真 排序 + 倒序；显示评者头像
  - 正文与评审栏可拖动分栏（默认 1:2，比例本地持久化）；评审栏字号与正文一致
- **Ctrl+F12**：任意界面打开 / 收起开发者工具（打包版同样可用）

### 改进

- **排序**：新增「按字数」排序（接口不支持，客户端本地实现）；全部排序支持倒序（统一 ↑/↓ 切换，`order=-field` 服务端升序）；评分 / 点赞 / 评论 / 阅读相同的文章排名相同（并列同名次）
- **活动卡片**：两行统计表格化对齐——第一行 作品 / 作者 / 字数 / 阅读量，第二行 评审人数 / 评审总数（仅已结束活动）；描述按分号换行
- **文章卡片**：标记字数（如「1.6 万 字」）
- **阅读页头部**：评分大数字靠右放大（与评分同色），「评审这篇文章」按钮上下排布
- 活动徽章、任务红点靠右对齐；活动列表页顶部展示活动介绍（封面 / 主题 / 截止时间）

### 修复

- **Windows 版无法打开界面**：Linux 交叉打包时原生模块 `better-sqlite3` 误打包为 Linux 版二进制（`not a valid Win32 application`），现由 `scripts/win-prebuild.mjs` 自动注入 Windows 版 prebuild（ABI=132），打包流程全自动
- 已评审文章不再「展示 + 编辑表单」同时显示
- 接口适配：`order=-field` 升序语法、活动状态 `activeStatus`（1=进行中 / -1=评审中 / 0=已结束）、置顶文章取数等实测结论已归档至 `doc/api-research.md`

## v0.0.1（2026-08-05）

首个发布版本（M0–M3 功能）：

- **写作**：荒启账号登录（账号密码 / 手机验证码）、会话加密持久化免登录；本地 Markdown 编辑（CodeMirror 6，自动保存 + Ctrl+S）；草稿 / 待审核 / 已发布 / 已拒绝四态管理与同步
- **阅读**：推荐（精选 / AI 模型）、连载、练笔活动、作品库五大栏目；正文安全净化渲染防 XSS；列表排序（评分 / 点赞 / 评论 / 阅读 / 时间 / 回复）
- **评审**：官方五维评审体系（设定 / 文笔 / 人物 / 情节 / 思想性），查看与提交评审、态度表态（开心 / 有用 / 认真）
- **安全**：凭据经系统级加密（safeStorage）仅存主进程；渲染层沙箱隔离；远端内容白名单净化
- **打包**：Windows NSIS + Linux deb / AppImage
