# 产品与 UX 决策记录

> 本文件是 `doc/design-1.md` 的子系统文档之一，记录通过 grilling 确认的产品级决策。
> 技术实现细节不在此记录，由开发计划与架构文档决定。

## 1. 范围与边界

| 决策 | 结论 |
| --- | --- |
| 交付物 | 当前先形成完整开发计划；代码重构后续按计划执行 |
| 未实现功能 | 不纳入：AI 能力、版本管理等留作未来展望 |
| 账号 | 单账号单会话 |
| 登录方式 | 仅账号密码 |
| 平台 | Windows / Linux / macOS 同优先级；保留平台原生差异 |
| 语言 | 仅简体中文；不引入 i18n |
| 分发 | 仅 GitHub Releases |
| 数据 | 不采集遥测、不自动上报 |
| 新增能力 | 不新增导入/导出、自动备份、社区治理、通知偏好 |

## 2. 用户可见变化

| 决策 | 结论 |
| --- | --- |
| 是否允许 | 允许用户可见变化 |
| 允许类别 | 一致性修复、文案清晰化、空态/错误态优化、基础可访问性、微小交互打磨、冗余/过时入口清理 |
| 视觉方向 | 保持现有极简视觉语言；不做大幅重设计 |
| 审批 | 每项用户可见变更需先登记，经用户确认后再实现 |
| 半成品功能 | 允许在“不新增未规划功能”前提下补完/理顺现有功能 |

## 3. 数据与本地文件

| 决策 | 结论 |
| --- | --- |
| 退出登录 | 仅清会话，保留本地文档/索引/设置 |
| 同步冲突 | 默认保留本地，提供冲突列表与覆盖远端/保留远端/另存副本选择 |
| 删除 | 默认不联动远端；二次确认；移入回收站并提示可恢复 |
| 文件操作 | 支持文件与文件夹重命名/移动 |
| 配图随动 | 移动/重命名文章时 `.image` 目录自动跟随 |
| 远端关联 | 重命名/移动后保留远端关联并更新本地路径 |
| 操作入口 | 文件树右键菜单 + 写作首页卡片菜单 |
| 文件树 | 仅显示 md 文件与文件夹 |

## 4. 启动与导航

| 决策 | 结论 |
| --- | --- |
| 启动默认页 | 始终进入推荐首页 |
| 用户页入口 | 已登录用户仍可从左栏用户卡进入本人用户页 |
| 默认排序 | 推荐/连载/活动默认时间降序；作品库默认评分降序 |
| 无评分分类 | 科幻杂谈/官方公告/外文翻译回退时间降序且不显示评分榜 |
| 阅读页右栏 | 默认不打开 |
| 评审面板 | 默认显示“所有评审” |
| 作品库首页 | 保留“最新讨论/最新评审”信息流 |

## 5. 编辑、发布、评审与媒体

| 决策 | 结论 |
| --- | --- |
| 新建草稿 | 纯空白，无模板 |
| 发布默认 | 类型必填；活动默认不参加；公开阅读默认公开 |
| 发布后本地状态 | 标记为待审核 |
| 媒体上传失败 | 保留本地占位并提示错误，允许重试 |
| 评审审核状态 | 保持现有兜底文案，不虚构审核状态 |
| 个人资产 | 仅保留现有“我的收藏” |

## 6. 交互与反馈

| 决策 | 结论 |
| --- | --- |
| 全局搜索 | Ctrl+F 搜索/替换覆盖正文与标题/摘要 |
| 通知点击 | 跳转到对应文章/评审/评论/用户页 |
| 错误提示 | 就地错误 + 可重试，不弹全局打断框 |
| 更新提示 | 横幅提示 + 用户手动下载安装 |
| 空态/错误态 | 简洁文字 + 可操作按钮 |
| 布局持久化 | 左栏折叠/宽度、右栏开关/宽度、评审分栏比例 |
| 离线体验 | 保持现状，重点保证本地写作可用，不额外做全局断网指示 |
| 可访问性 | 基础可达性：键盘可操作、焦点可见、按钮/图标有语义、颜色不唯一传达信息 |
