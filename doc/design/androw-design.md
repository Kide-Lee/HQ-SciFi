# 荒启科幻 Android 客户端界面设计

> 版本：v2 草案 · 2026-11-22
> 范围：只定义 Android 手机端的界面结构、导航、返回、状态与交互；不涉及接口协议、Rust 内核实现和桌面端全部改造。
> 关联：`doc/design/简介.md`（桌面端布局）、`doc/design/Tauri迁移计划.md` §9（Android 复用内核）。

一句话：**功能与内容同桌面端，布局按手机重排；复用 `hqsf-core`，窗口、文件、通知、键鼠/触摸这些平台层在 Android 重写。**

## 1. 与桌面端的关系

### 1.1 复用什么

- Rust 内核（`crates/hqsf-core`）：业务规则、网络、数据库、markdown、同步、评审。
- 渲染层的列表、卡片、编辑器、正文渲染：能直接用的尽量复用，只改外层导航与布局。
- 数据与状态语义：页签内容、稿件四态、消息分类、评审规则以桌面端为准。

### 1.2 必须在 Android 重做什么

| 桌面能力 | Android 做法 |
|---|---|
| 三栏 + 可拖宽分栏 | 单栏 + 底部导航；右栏变右侧抽屉 |
| 窗口最小化/最大化/关闭 | 不存在，删除 |
| 鼠标悬停提示 / 右键菜单 | 长按弹出底部菜单 |
| “打开本地存档目录” | App 私有目录；改为“导出存档” |
| 桌面安装包自动更新 | 首版不做；以后若做，下载 APK 需“安装未知应用”权限 |
| 键盘快捷键 | 触摸手势 + 工具栏按钮 |

### 1.3 有意保留的差异

- 首页顺序为 **推荐 / 活动 / 连载 / 作品库**；桌面端为 推荐 / 连载 / 活动 / 作品库。活动更重要，也适合手机短会话。
- “我的”默认 **动态**；桌面端用户页同步改为“本人默认动态、他人默认主页”。
- 搜索页未输入时，中部展示“推荐 / 精选”内容（有意新增，桌面端的作品库首页没有这块）。
- 桌面左栏的“精选 / AI 模型”入口移动端暂不提供（桌面端也未实现）。

## 2. 全局结构

### 2.1 主界面

顶栏 + 中部内容 + 底部导航栏。

底部导航固定 5 个：**首页、我的、写作、消息、设置**；“写作”突出显示。除文章、编辑器、他人主页、私聊等压栈页外，底部导航常驻。

- 底部导航要处理手势条/安全区，不能压在系统导航上。
- 消息图标右上角红点：有任意未读消息时显示（桌面判定为 `totalUnread > 0`）。
- 登录不是底部导航项；未登录时“我的”显示登录引导。

### 2.2 一级页签

每个目的地的顶栏是它的一级页签；页签多时横向滚动，不折叠成“更多”。

| 目的地 | 页签 | 默认 |
|---|---|---|
| 首页 | 推荐、活动、连载、作品库 | 推荐 |
| 我的（本人） | 动态、收藏、粉丝、文章、评审、评论 | 动态 |
| 我的（他人） | 主页、粉丝、文章、评审、评论 | 主页 |
| 写作 | 本地存档、草稿、待审核、已发布、已拒绝 | 本地存档 |
| 消息 | 互动、私聊、通知 | 互动 |
| 设置 | 系统、界面、用户 | 系统 |

规则：

- 一级页签支持左右滑动切换，但**页签切换不进入返回栈**。
- 进入“我的”一律回到**动态页签顶部**；即使上次停在粉丝/收藏，也回动态。点击底部“我的”（即使已经在“我的”）同样回动态顶部。
- 他人主页是压栈页，默认“主页”，没有动态/收藏页签（与桌面一致）。
- 消息页不再有“历史”；阅读历史移到“我的”顶栏右侧图标。
- “我的”未登录时只有登录引导，不显示 7 个页签。

### 2.3 顶栏

- 左侧：目的地页签条；压栈页为返回按钮 + 标题。
- 右侧：该目的地的操作（搜索、新建、历史、文章栏等）。
- 首页右侧是搜索按钮；写作右侧是三个操作；我的右侧是历史图标。
- 不显示桌面窗口按钮；标题过长省略，不换行。

## 3. 返回

### 3.1 规则

1. **压栈页**：返回 = 桌面端该页顶栏返回按钮的语义。
   - 文章 → 打开它的列表/来源页，保留滚动位置。
   - 他人主页 → 上一个页面。
   - 私聊 → 消息列表。
   - 编辑器 → 写作或文章页；有未保存修改时先确认。
   - 搜索态 → 退出搜索，回到进入前的首页页签与位置。
   - 登录/协议 → 关闭覆盖层或退出。
2. **目的地页签根页**：返回 = 首页（推荐）。
3. **首页根页**：返回 = 退出。首次提示“再按一次退出”，2 秒内再按才退出。
4. **通知冷启动**直接打开文章/私聊：栈底补来源页（消息），返回回消息而不是首页。
5. **外部深链/分享进入**：同上，栈底补首页或消息。

### 3.2 不进入返回栈

- 底部导航切换、一级页签切换、二级页签切换。
- 打开/关闭右侧抽屉（文章栏、历史）不压栈；返回键优先关抽屉。

## 4. 页面规格

### 4.1 首页

**顶栏**：页签 推荐 / 活动 / 连载 / 作品库，右侧搜索。默认推荐。

**推荐**：同桌面端 `RecommendHome`。活动轮播、推荐/精选内容、文章卡；点文章进文章页，点作者进他人主页，点活动进活动页。

**活动**：同桌面端 `ActivityHome`。活动列表卡片；点进活动详情/活动文章。有未完成评审时，“活动”页签显示红点（对应桌面左栏活动按钮的红点规则）。

**连载**：同桌面端 `SerialHome`。推荐合集、推荐连载；点进合集/连载文章列表。

**作品库**：

- 二级页签由 `metasList type=category` 动态生成，默认“原创作品”；接口未就绪时用桌面现有四项（原创作品、科幻杂谈、官方公告、外文翻译）兜底。移动端不把分类写死。
- 二级页签只点击切换，不参与左右滑。
- 内容为对应分类的文章列表；点文章进文章页。

**搜索态**：

- 点搜索后，顶栏整条变为搜索框；下方有“时空乱流”“前往官网”按钮。
- 未输入时，中部展示“推荐 / 精选”内容（有意与桌面端不同）。
- 输入后，中部变为搜索结果，分为 **文章 / 评论 / 评审 / 用户** 四类并带数量；点结果进对应详情。
- 搜索态仍属首页，底部导航保留；返回退出搜索态，回到进入前的页签与位置。

### 4.2 我的

**未登录**：整页为登录引导，说明登录后启用同步、发布、评审、消息；底部导航保留。登录是覆盖层/独立页，不新增底部导航项。

**本人页签**：动态 / 收藏 / 粉丝 / 文章 / 评审 / 评论，默认动态；每次进入回动态顶部。

- 动态：关注动态流；未登录不可用，提示登录。
- 收藏：本人收藏文章；未登录不可用。
- 粉丝：顶部有“粉丝 / 关注”切换（桌面端在粉丝页内切换）。粉丝列表可回关/私聊，关注列表可取关/私聊。
- 文章：本人文章列表，同桌面。
- 评审 / 评论：本人评审、评论列表，同桌面。
- 顶栏右侧“历史”图标：进入阅读历史（对应桌面右栏“历史”页），压栈页，返回回“我的”。

**他人主页**：压栈页，隐藏底部导航；页签 主页 / 粉丝 / 文章 / 评审 / 评论，默认主页；顶部返回；操作有关注、私聊；内容同桌面端用户页。

### 4.3 写作

**顶栏**：页签 本地存档 / 草稿 / 待审核 / 已发布 / 已拒绝；右侧三个按钮：

1. 新建本地草稿 → 进入编辑器。
2. 导出存档（替代桌面“打开本地存档目录”）：把本地存档打包导出/分享到系统文件选择器。
3. 从云端下载草稿与状态。

**本地存档**：树形目录，同桌面。长按条目弹出底部菜单：重命名、移动、同步到草稿、导出；“复制路径 / 在文件管理器中显示”在 Android 无意义，改为“导出 / 分享”。

**草稿 / 待审核 / 已发布 / 已拒绝**：列表同桌面，点击进编辑器或文章页；状态流转、提交审核、撤回等以桌面为准。

- 默认本地存档。
- 空态、加载态、失败文案同桌面。

### 4.4 消息

**页签**：互动 / 私聊 / 通知，默认互动。

- 互动 = 评论 + 评审；私聊 = 私聊；通知 = 粉丝 + 系统 + 财务（与桌面消息页分类一致）。
- 有未读时底部“消息”图标显示红点；页签内未读样式和已读规则与桌面一致。
- 未登录：显示登录引导；登录后可看。
- 私聊：点会话进聊天页（压栈，返回回消息列表）；不用桌面右栏的窄栏形态。
- 阅读历史不在消息页。

### 4.5 设置

**页签**：系统 / 界面 / 用户，同桌面。

- 系统：检查更新、清除缓存、日志/诊断入口、版本号。
- 界面：主题、字号、阅读设置，同桌面。
- 用户：账号信息、退出登录、隐私说明、开源许可。
- 不出现桌面窗口相关设置。应用商店合规（软著/备案）不做，但运行时权限说明和隐私说明要有。

### 4.6 文章页

压栈页，隐藏底部导航。

- 顶栏：返回、文章标题、右侧“文章栏”按钮。
- 正文：同桌面 `ReaderView`，markdown、图片（走 `hqsf-img` 缓存协议）、代码块、公式、嵌入媒体（网易云 / QQ 音乐 / B 站）。
- 文章栏：右侧抽屉，含 目录 / 评论 / 评审 / 搜索，同桌面右栏。
- 底部操作条：投币、点赞、收藏、分享、评审（桌面为悬浮组，手机改底部条，便于单手）。
- 评分/评审入口与桌面一致；点评审进评审面板（我的评审 / 所有评审）。
- 评论区同桌面，支持加载更多。
- 返回：回来源列表并保留滚动位置。

### 4.7 编辑器

压栈页，隐藏底部导航。

- 顶栏：返回、文章标题、可视化/编辑模式切换、右侧“文章栏”。
- 工具栏：贴在虚拟键盘上方，随键盘上移，不遮光标。
- 文章栏：右侧抽屉，同桌面右栏。
- 保存/发布：保存、同步到草稿、发布、违禁词检查、字数限制（不足 3000 或超 33000 禁发布，同桌面）。
- 发布表单：桌面弹窗在手机上改为全屏页（类型 / 标签 / 活动 / 公开范围），字段与校验同桌面。
- 返回：有未保存修改先确认；保存行为与桌面一致。

### 4.8 登录与协议

- 首次启动先过协议门，未同意不进入应用；协议标题改为“荒启科幻移动客户端用户协议”（桌面文案是“桌面客户端”）。
- 未登录可浏览、可本地写作；同步、发布、评审、消息需要登录。
- 登录是覆盖层/独立页，不占底部导航；登录成功后回到进入前的位置。
- 荒启平台协议在登录时勾选，同桌面。

## 5. 平板与折叠屏

### 5.1 调研结论

- 业界主流按**窗口宽度**分档，不按“设备是不是平板”。Material 3 / Android 窗口尺寸类别为：compact <600dp、medium 600–839dp、expanded 840–1199dp；再往上还有 large、extra-large。
- Android 确实有“设备类型”和“方向”的声明：`smallestScreenWidthDp >= 600` 常被视为平板（对应 `-sw600dp` 资源限定符）；`UiModeManager.getCurrentModeType()` 可以返回 `UI_MODE_TYPE_TABLET`；`Configuration.orientation` 可以读横竖屏。
- 但这些值在多窗口、自由窗口、折叠屏和 OEM 定制下不能代表当前窗口形状，官方建议按窗口大小适配，而不是按设备类型。
- 折叠屏用 Jetpack WindowManager 的 `FoldingFeature` 判断铰链/姿态（平放、半开、书本/桌面模式）；首版不做，v2 再加。

### 5.2 本项目的规则（v2 再实现）

- 手机（窗口宽度 <600dp）：本文档的底部导航布局。
- 600–839dp：左侧导航收成图标 rail + 内容区；右栏默认收起。
- ≥840dp：左栏 + 主区 + 右栏三栏，接近桌面；仍不显示窗口按钮，不用 hover/右键。
- 折叠屏展开、旋转、分屏导致窗口变化时：保留编辑器内容、光标、滚动位置，不重建页面。
- 实现上用 WebView 的 `window.innerWidth` / CSS 媒体查询判断（CSS px 约等于 dp），不用设备型号或 UA。
- 首版只保证手机；平板/折叠屏按本节 v2 计划排期。

- Android window size classes：https://developer.android.com/develop/ui/compose/layouts/adaptive/window-size-classes
- Android 大屏适配：https://developer.android.com/guide/topics/large-screens/support-different-screen-sizes

## 6. 交互与状态

### 6.1 手势

- 屏幕左右边缘各 24dp 留给系统返回，一级 pager 不响应。
- 一级页签左右滑只在空白/纵向列表区域生效；轮播图、横向列表、代码块、表格优先消费横向手势。
- 二级页签（作品库分类）只点击，不滑动。
- 页签条本身可横向滚动；7 个页签在 360dp 宽下不挤成两行。

### 6.2 状态记忆

- 冷启动：各目的地按默认页签。
- 本次运行内：同一页签内从详情返回保留滚动位置；切换底部导航后回来，除“我的”回动态顶部外，其余目的地保留页签与位置。
- 进程被杀：回默认页，第一版不做持久化恢复。
- 旋转/折叠/分屏：不丢编辑器内容与滚动位置。

### 6.3 未读与红点

- 底部消息红点 = 有任意未读（`totalUnread > 0`）；进入消息页后的已读规则同桌面右栏消息页。
- 首页“活动”页签红点 = 有未完成评审（同桌面活动按钮规则）。
- 不做数字角标，与桌面一致。

### 6.4 权限与系统行为

- 通知：Android 13+ 在合适时机申请 `POST_NOTIFICATIONS`；拒绝时提示“将收不到消息提醒”，不阻断使用。
- 图片：优先用系统 Photo Picker；相机/相册被拒时提供“从文件选择”降级。
- 自更新（若做）：下载 APK 后跳系统安装，需要“安装未知应用”权限；首版可以不做。
- 返回手势/系统导航：使用系统返回，不拦截；只有首页根页双击退出。
- 键盘：编辑器和搜索框处理 IME 避让与 `visualViewport` 变化。

## 7. 暂不做 / 待定

- 精选 / AI 模型入口（桌面也未实现）。
- SAF 共用文件夹：首版 App 私有目录 + 导出；如果“手机和电脑共用草稿文件夹”成为必须，再立项。
- 平板/折叠屏三栏：v2。
- 应用商店上架与商店合规（软著/备案）；保留运行时权限与隐私说明。
- App 内自动更新：首版手动下载安装。
