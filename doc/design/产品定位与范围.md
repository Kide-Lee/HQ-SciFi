# 产品定位与范围

> 本文件是 `doc/design-1.md` 的子系统文档之一，描述产品定位、目标用户、功能范围与边界。

## 1. 概述

本应用为 [荒启科幻](https://www.huangqisf.com/h5/#/) 的电脑客户端，为用户提供 **写作 — 阅读 — 评审** 的一站式解决方案。

核心价值：把荒启科幻的在线写作、投稿与社区阅读能力搬回本地 —— 用本地 Markdown 文件写作，随时同步草稿、一键发布，并在本地直接阅读与评审他人作品。

## 2. 目标用户

- 在荒启科幻上进行创作与阅读的写作者；
- 习惯本地编辑、需要离线写作与本地存档的用户；
- 希望把在线阅读、评审、用户互动整合到桌面环境的用户。

## 3. 功能范围

| 功能域 | 能力 |
| --- | --- |
| 写作闭环 | 本地 Markdown 双模式编辑、自动保存、四态管理、同步、发布、远端文章编辑/转存为草稿、本地存档树与卡片、图片随文同步 |
| 阅读浏览 | 推荐、连载、活动、作品库、文章列表排序/分页、正文安全渲染 |
| 评审 | 五维评审、我的/所有评审、排序、评审任务、活动期评分隔离与匿名规则 |
| 评论与互动 | 评论区、楼中楼、评审评论聚合与跳转、点赞/收藏/投币、全局搜索 |
| 用户系统 | 用户主页、动态/收藏/粉丝/文章/评审/评论、关注、签到、资料编辑、私聊 |
| 系统能力 | 登录/会话、协议门、设置、自动更新、通知中心、缓存管理、卸载 |
| 基础设施 | 单实例锁、API 配置驱动、本地索引、图片缓存、无边框窗口、快捷键与全局搜索 |

## 4. 明确边界（范围防蔓延）

- 不做账号注册/找回密码等账号体系，复用荒启现有账号。
- 不做完整的离线内容库；在线内容按需拉取，不整站缓存。
- 不做版本管理、AI 能力（AI 模型栏目仅作浏览入口）。
- 不覆盖荒启官方的所有功能边界，优先保持“写作、阅读、评审”三环闭环。

## 5. 已确认的产品决策

完整决策记录见 `产品与UX决策记录.md`。要点：

- 单账号单会话；登录方式仅账号密码。
- Windows / Linux / macOS 同优先级；保留平台原生差异。
- 仅 GitHub Releases 分发；不采集遥测、不自动上报。
- 启动始终进入推荐首页；已登录用户仍可从用户卡进入用户页。
- 本地文件支持重命名/移动，配图自动跟随，保留远端关联。
- 新建草稿纯空白；发布默认类型必填、活动不参加、公开阅读公开；发布后本地状态为待审核。
- 阅读页右栏默认不打开；评审面板默认“所有评审”。
- 作品库默认评分排序；无评分分类回退时间降序且不显示评分榜。
- 允许用户可见变化，但需按 `产品与UX决策记录.md` 的类别与审批流程执行。

## 6. 界面信息架构（简要）

- **左栏**：五大栏目（写作 / 推荐 / 连载 / 活动 / 作品库）+ 用户卡 + 文件树/栏目树。
- **顶栏**：页面标题、返回、窗口控件、右栏开关、折叠左栏等。
- **主区**：写作编辑器 / 阅读页 / 栏目列表 / 用户页等。
- **右栏**：目录、评论、评审、全局搜索/替换、消息等可组合面板。
- **设置弹窗**：系统 / 界面 / 用户三组设置。
