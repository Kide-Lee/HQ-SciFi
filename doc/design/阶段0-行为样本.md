# 阶段 0：高风险纯函数行为样本

> 本文件记录重构前需要保留的高风险纯逻辑行为样本，供后续回归对照。
> 样本来源：`src/main/activity-rules.ts`、`src/renderer/src/lib/activity.ts`、`src/renderer/src/lib/category.ts`、`src/renderer/src/lib/sanitize.ts`、`src/renderer/src/components/ArticleListView.tsx`。
> 后续阶段若把这些逻辑移动到 `domain/` 或 `lib/`，必须以本文件样本验证行为不变。

## 1. 活动期评分隔离：`sanitizeArticleList`

**函数**：`src/main/activity-rules.ts` 的 `sanitizeArticleList(items, mids)`

**规则**：
- 只有文章 `active[].mid` 命中 `mids` 时脱敏；
- 脱敏后 `score = '-.-'`、`hideScore = true`、作者展示字段改为“匿名用户”；
- 不改变 `authorInfo.uid` 等内部字段。

**样本**：

```ts
const items = [
  {
    cid: 'a1',
    score: '8.5',
    active: [{ mid: 10, name: '第10期' }],
    authorInfo: { uid: '123', name: '作者A', avatar: 'https://x/a.png' }
  },
  {
    cid: 'a2',
    score: '9.0',
    active: [{ mid: 99, name: '结束活动' }],
    authorInfo: { uid: '456', name: '作者B', avatar: 'https://x/b.png' }
  }
]
const mids = new Set(['10'])
sanitizeArticleList(items, mids)
```

**预期输出**：

```ts
[
  {
    cid: 'a1',
    score: '-.-',
    hideScore: true,
    active: [{ mid: 10, name: '第10期' }],
    authorInfo: { uid: '123', name: '匿名用户', nickname: '匿名用户', screenName: '匿名用户', avatar: '', headImg: '', headImgUrl: '', avatarUrl: '' }
  },
  {
    cid: 'a2',
    score: '9.0',
    // 未命中 mids，不脱敏
    active: [{ mid: 99, name: '结束活动' }],
    authorInfo: { uid: '456', name: '作者B', avatar: 'https://x/b.png' }
  }
]
```

## 2. 评审列表脱敏：`sanitizeReviewList`

**规则**：
- 活动评审且非本人时隐藏评分：`actualscore = '-.-'`、`score = '-.-,-.-,-.-,-.-,-.-'`、`hideScore = true`；
- 自己的评审始终保留评分。

**样本**：

```ts
const items = [
  { id: 1, uid: 'u1', activeid: 10, actualscore: '8.0', score: '8,8,8,8,8', hideScore: false },
  { id: 2, uid: 'u2', activeid: 10, actualscore: '7.5', score: '7,8,7,8,8', hideScore: false },
  { id: 3, uid: 'u1', activeid: 99, actualscore: '9.0', score: '9,9,9,9,9', hideScore: false }
]
const mids = new Set(['10'])
const myUid = 'u1'
sanitizeReviewList(items, mids, myUid)
```

**预期输出**：

```ts
[
  // 自己的评分保留
  { id: 1, uid: 'u1', activeid: 10, actualscore: '8.0', score: '8,8,8,8,8', hideScore: false },
  // 他人活动评审隐藏
  { id: 2, uid: 'u2', activeid: 10, actualscore: '-.-', score: '-.-,-.-,-.-,-.-,-.-', hideScore: true },
  // 非活动不脱敏
  { id: 3, uid: 'u1', activeid: 99, actualscore: '9.0', score: '9,9,9,9,9', hideScore: false }
]
```

## 3. 评论列表脱敏：`sanitizeCommentList`

**规则**：
- 剔除服务端占位评论；
- 在匿名活动文章下，作者本人的评论作者字段改为“匿名用户”、头像清空。

**样本**：

```ts
const items = [
  { cid: 'c1', text: '活动期间，作者评论回复暂时隐藏', author: '作者A', avatar: 'https://x/1.png', authorId: '123', articleAuthorId: '123' },
  { cid: 'c1', text: '这是正常评论', author: '作者A', avatar: 'https://x/2.png', authorId: '123', articleAuthorId: '123' },
  { cid: 'c2', text: '非匿名单篇评论', author: '作者B', avatar: 'https://x/3.png', authorId: '456', articleAuthorId: '456' }
]
const anonymousCids = new Set(['c1'])
sanitizeCommentList(items, anonymousCids)
```

**预期输出**：

```ts
[
  // 服务端隐藏占位被过滤
  { cid: 'c2', text: '非匿名单篇评论', author: '作者B', avatar: 'https://x/3.png', authorId: '456', articleAuthorId: '456' },
  // 匿名文章下作者本人评论脱敏
  { cid: 'c1', text: '这是正常评论', author: '匿名用户', avatar: undefined, authorId: '123', articleAuthorId: '123' }
]
```

## 4. 活动阶段判定：`activityPhase` / `isActiveReviewing`

**规则**：
- `activeStatus = 1` → `ongoing`；
- `activeStatus = -1` → `reviewing`；
- 其他 → `ended`；
- `ongoing` 或 `reviewing` 需要隐藏评分榜/评分/排名。

**样本**：

| 输入 | 预期 |
| --- | --- |
| `{ activeStatus: 1 }` | `ongoing` / `true` |
| `{ activeStatus: -1 }` | `reviewing` / `true` |
| `{ activeStatus: 0 }` | `ended` / `false` |
| `{ activeStatus: undefined }` | `ended` / `false` |

## 5. 分类禁用评分：`isReviewDisabledCategory` 系列

**规则**：`科幻杂谈`、`官方公告`、`外文翻译` 三类不开评审、不显示评分。

**样本**：

| 输入 | 预期 |
| --- | --- |
| `isReviewDisabledCategoryName('科幻杂谈')` | `true` |
| `isReviewDisabledCategoryName('')` | `false` |
| `isReviewDisabledCategoryTitle('作品库 · 科幻杂谈')` | `true` |
| `isReviewDisabledCategoryTitle('作品库')` | `false` |
| `isReviewDisabledArticle({ category: [{ name: '官方公告' }] })` | `true` |
| `isReviewDisabledArticle({ category: [{ name: '连载' }] })` | `false` |

## 6. 匿名作者本人显示：`anonymousAuthorDisplayName`

**规则**：
- 文章必须是匿名文章；
- 评论/评审者 uid 与文章作者 uid 相同，或双方都是匿名 uid，则显示“匿名用户”；
- 其他情况保留原始显示名。

**样本**：

| 文章侧 | itemAuthorId | 原始名 | 预期 |
| --- | --- | --- | --- |
| `{ authorId: '123', isAnonymous: true }` | `'123'` | `作者A` | `匿名用户` |
| `{ authorId: '0', isAnonymous: true }` | `'0'` | `游客` | `匿名用户` |
| `{ authorId: '123', isAnonymous: true }` | `'456'` | `读者B` | `读者B` |
| `{ authorId: '123', isAnonymous: false }` | `'123'` | `作者A` | `作者A` |
| `null` | `'123'` | `作者A` | `作者A` |

## 7. 评分榜排名：竞赛式并列排名

**来源**：`ArticleListView.tsx` 中的 `rankOf`。

**规则**：
- 仅对 `score / likes / commentsNum / views` 四种排序显示排名；
- 按降序键值计算，与当前展示排序方向无关；
- 相同键值同 rank，下一名次跳号（`1,2,2,4`）；
- 有空键值（`null` / `score='-.-'`）不参与排名。

**样本**（`listOrder='score'`）：

```ts
const list = [
  { cid: 'A', score: '8.0' },
  { cid: 'B', score: '9.0' },
  { cid: 'C', score: '9.0' },
  { cid: 'D', score: '7.0' },
  { cid: 'E', score: '-.-' }
]
```

**预期排名映射**：

```ts
{ A: 3, B: 1, C: 1, D: 4, E: undefined }
```

**样本**（`listOrder='likes'`）：

```ts
const list = [
  { cid: 'A', likes: 100 },
  { cid: 'B', likes: 80 },
  { cid: 'C', likes: 80 },
  { cid: 'D', likes: 30 }
]
```

**预期排名映射**：

```ts
{ A: 1, B: 2, C: 2, D: 4 }
```

## 8. 封面可点击作者判定

**规则**：匿名作者（uid 为 `''` / `'0'`，或显示名“匿名用户”/“匿名”）不可点击进入用户页。

**样本**：

| 作者信息 | 预期 |
| --- | --- |
| `{ uid: '123', name: '作者A' }` | 可点击 |
| `{ uid: '0', name: '匿名' }` | 不可点击 |
| `{ uid: '', name: '匿名用户' }` | 不可点击 |
