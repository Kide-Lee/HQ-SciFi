# 测试与回归验证计划

> 本文件是 `doc/design-1.md` 的子系统文档之一，定义各阶段必须执行的验证项。
> 核心目标：**证明重构未改变用户可见功能**。

## 1. 验证工具

| 工具 | 用途 |
| --- | --- |
| `npm run typecheck` | 主进程 + 渲染层类型检查 |
| `npm run build` | electron-vite 构建 |
| `npm run dev:test` / `start:test` | 本地 RuleApi / 测试模式隔离验证 |
| `npm run build:linux` / `build:win` / `build:mac` | 打包验证（按当前平台可执行） |
| CDP 调试脚本 | 运行中应用只读探测、截图、交互验证 |
| 真实账号 | 登录、同步、发布、评审等完整闭环 |

## 2. 全局必跑项（每个阶段）

- [ ] `npm run typecheck`
- [ ] `npm run build`
- [ ] 至少一个平台的 `build:*` 在阶段 2 后执行一次
- [ ] `dev:test` 启动不报错、不混入正式 userData
- [ ] 核心行为路径抽查（见阶段矩阵）

## 3. 行为基线路径

### 3.1 首次启动与登录

- [ ] 首启显示协议门，同意后进入主界面。
- [ ] 未登录可浏览/写作。
- [ ] 登录后可同步/发布/评论/评审。
- [ ] 退出登录清除会话，本地内容不丢失。

### 3.2 写作闭环

- [ ] 新建草稿 → 写入本地存档（纯空白）。
- [ ] 可视化/源码编辑可切换，内容一致。
- [ ] 自动保存与 Ctrl+S 生效。
- [ ] 同步到草稿成功。
- [ ] 发布表单可填写并提交；发布后本地状态为待审核。
- [ ] 四态在左栏正确显示。
- [ ] 本地文件/文件夹可重命名与移动；配图自动跟随；保留远端关联。

### 3.3 阅读与浏览

- [ ] 启动始终进入推荐首页；已登录用户可从用户卡进入用户页。
- [ ] 推荐/连载/活动/作品库列表可加载。
- [ ] 默认排序：推荐/连载/活动时间降序；作品库评分降序；无评分分类回退时间降序且不显示评分榜。
- [ ] 排序、倒序、字数、并列排名正确。
- [ ] 文章卡片封面兜底。
- [ ] 活动期文章不暴露评分/排名。
- [ ] 阅读页右栏默认不打开；评审面板默认“所有评审”。

### 3.4 评审与评论

- [ ] 评审面板“我的评审/所有评审”双视图。
- [ ] 提交/编辑评审成功。
- [ ] 态度表态成功。
- [ ] 评论发表/回复成功，评审评论内嵌展开。
- [ ] 匿名规则正确显示。

### 3.5 用户与通知

- [ ] 头像进入用户页。
- [ ] 关注/粉丝/文章/评审/评论/动态可查看。
- [ ] 签到可用。
- [ ] 未读红点与消息中心可用。
- [ ] 通知点击跳转到对应文章/评审/评论/用户页。
- [ ] 私聊会话可打开并发送。

### 3.6 设置与更新

- [ ] 主题/字体/缩放/自定义 CSS/JS 生效。
- [ ] 自动更新开关持久化。
- [ ] 清除缓存可执行。
- [ ] 卸载入口存在（仅打包环境验证）。
- [ ] 左栏折叠/宽度、右栏开关/宽度、评审分栏比例在重启后保持。
- [ ] 媒体上传失败时保留占位并允许重试。

## 4. 阶段验证矩阵

| 阶段 | 重点验证 | 额外验证 | 通过标准 |
| --- | --- | --- | --- |
| 阶段 0 | 行为基线全量 | 当前 `typecheck/build` 基线 | 基线清单完整、构建通过 |
| 阶段 1 | 登录、同步、阅读、评审 | 类型检查、preload 类型一致性 | `window.hqsf.*` 方法签名未变 |
| 阶段 2 | 登录、同步、阅读、评审、用户、设置 | handler 清单对比、`dev:test` | channel 与返回约定未变 |
| 阶段 3 | 写作闭环、阅读、评审、用户页、设置、通知 | domain/adapter 单测 | 无行为差异、大文件拆分完成 |
| 阶段 4 | 全部 UI 路径 | 截图对比、feature 逐项验证 | 交互/样式无可见变化 |
| 阶段 5 | 全量行为基线 | 单测、端到端脚本、多平台构建 | 基线全部通过 |

## 5. 高风险回归项

| 功能 | 风险点 | 验证方法 |
| --- | --- | --- |
| 活动期评分隔离 | 进行中/评审中活动文章不应有评分/排名 | 真实活动数据或 mock 数据 |
| 匿名规则 | 匿名文章下的作者本人评审/评论显示「匿名用户」 | 真实匿名文章或构造数据 |
| 并列排名 | 1,2,2,4 跳号规则 | 单元测试 + 列表人工验证 |
| 右栏状态 | `panelOpen`/`panelTab` 跨视图保持 | 各视图切换验证 |
| 编辑器 | Milkdown/CodeMirror 双模式切换、自动保存 | 编辑器手工验证 |
| 自定义 CSS/JS | 窗口加载后注入 | 设置后刷新/重启验证 |
| 多平台 | Linux/Windows 构建差异 | 至少当前平台 `build:*` 通过 |

## 6. 无法自动验证的内容

- 真实荒启账号登录、发布、审核状态流转。
- 真实通知/私聊推送。
- Windows/macOS 安装包行为。
- 弱网/风控/限流表现。

这些项在计划中标记为“待正常桌面环境验证”，不阻塞结构性重构，但需在发布前人工完成。
