# 应用简介、交互逻辑与功能说明

> 本文件是设计文档的用户视角入口，说明应用的定位、页面结构、核心功能、交互规则和主要用户流程。
> 产品决策以 `产品与UX决策记录.md` 为准；总体架构、主进程和渲染层的技术实现分别以 `总体架构与技术设计.md`、`主进程子系统设计.md` 和 `渲染层UI设计.md` 为准。

## 阅读指引

- 想了解应用是什么：阅读第 1 节“应用定位”。
- 想了解页面和导航：阅读第 3、4 节“启动与全局界面”“核心导航逻辑”。
- 想了解用户操作流程：阅读第 5–10 节，以及第 15 节的完整路径示例。

- 想确认当前版本不做什么：阅读第 16 节“功能边界总结”。

## 术语说明

- **本地文章**：存储在用户本地文档目录中的 Markdown 文件。
- **远端文章**：荒启科幻平台上的文章内容。
- **远端关联**：本地文章与远端文章之间保存的文章 ID、状态等对应关系。
- **四态**：本地索引中使用的草稿、待审核、已发布、已拒绝四种文章状态。
- **评审**：用户对文章进行的五维评分和文字评价；它不同于平台对文章的审核。

## 1. 应用定位

本应用是荒启科幻的桌面客户端，为用户提供“写作—阅读—评审”的一体化工作环境。

它把在线平台中的内容能力与本地文件能力结合起来：

- 用本地 Markdown 文件写作，正文长期保存在用户自己的文档目录中；
- 通过客户端同步草稿、发布文章、拉取远端文章状态；
- 在客户端内浏览推荐、连载、活动和作品库；
- 阅读文章、发表评论、提交评审、回复评审评论；
- 查看用户资料、动态、收藏、关注关系、通知和私聊消息。

应用不是一个独立的内容社区，也不是通用笔记软件。它复用荒启科幻现有账号与 API，重点保证本地写作体验和在线内容闭环。

## 2. 用户与权限模型

### 2.1 账号与登录

- 支持单账号、单会话。
- 登录方式仅为账号密码登录。
- 不提供注册、找回密码或其他账号管理能力；相关操作由荒启科幻平台负责。
- token 仅保存在主进程，并通过 Electron `safeStorage` 保护；渲染层只能获得不含 token 的用户会话信息。

### 2.2 未登录状态

未登录用户仍可：

- 浏览推荐、连载、活动、作品库；
- 打开文章并阅读；
- 使用本地文件写作、保存和管理草稿；
- 查看无需登录的公开内容。

需要登录后才能执行的操作包括：

- 同步到远端；
- 发布文章；
- 提交或编辑评审；
- 发表评论、回复、点赞、收藏或投币；
- 关注用户、签到或编辑个人资料；
- 查看或发送私聊消息。

当用户触发需要登录的操作时，应用打开登录界面；登录成功后返回原操作场景，不丢失当前页面状态。

### 2.3 退出登录

退出登录只清除会话和凭据，不删除本地资料。用户重新登录后，本地资料仍可继续使用。

退出登录不删除：

- 本地 Markdown 文件；
- 本地 SQLite 索引；
- 图片目录与缓存；
- 用户界面设置；
- 左栏、右栏和编辑器布局状态。

## 3. 启动与全局界面

### 3.1 启动流程

应用启动顺序为：

1. 获取单实例锁；
2. 加载应用设置与 API 配置；
3. 初始化本地数据库和文件索引；
4. 注册图片缓存协议；
5. 注册 IPC；
6. 创建安全窗口；
7. 加载协议状态、会话状态和用户界面状态；
8. 进入推荐首页。

推荐首页是固定启动入口，不根据上次退出时的页面恢复。登录用户仍然可以通过左栏用户卡进入自己的用户页。

首次启动或协议版本变化时，先显示用户协议。用户同意后进入应用主界面；如果用户不同意，则不能继续使用需要协议授权的应用功能。

### 3.2 应用布局

```
┌──────────────┬───────────────────────────────┬──────────────┐
│ 左栏          │ 顶栏 + 主内容区                │ 右栏（可选）  │
│              │                               │              │
│ 用户卡        │ 顶栏：标题、返回、窗口控件      │ 目录          │
│ 栏目入口      │                               │ 评论          │
│ 文件树        │ 主内容：编辑器/阅读/列表/用户页  │ 评审          │
│ 栏目树        │                               │ 搜索/消息      │
└──────────────┴───────────────────────────────┴──────────────┘
```

#### 左栏

左栏是应用的主要导航区域，包含：

- 用户卡；
- 写作入口；
- 推荐、连载、活动、作品库入口；
- 本地文件树；
- 远端四态树：草稿、待审核、已发布、已拒绝；
- 栏目或活动相关树形入口；
- 同步或刷新入口。

左栏可以折叠，也可以调整宽度。状态在重启后保持。

#### 顶栏

顶栏负责页面级导航和窗口控制：

- 显示当前页面标题；
- 返回上一级页面；
- 显示或隐藏右栏；
- 左栏折叠控制；
- 最小化、最大化/还原、关闭窗口等窗口操作。

#### 主内容区

主内容区根据当前导航状态显示相应内容：

- 写作首页或编辑器；
- 推荐、连载、活动、作品库列表；
- 文章阅读页；
- 用户主页；
- 设置弹窗或其他业务弹窗。

#### 右栏

右栏是可组合的辅助面板容器，可显示：

- 文章目录；
- 评论；
- 评审；
- 全局搜索与替换；
- 通知或消息相关内容。

阅读页右栏默认关闭。用户主动打开后，应用记住右栏开关、宽度和当前面板状态。

## 4. 核心导航逻辑

### 4.1 导航状态

应用通过统一 UI 状态管理当前：

- 当前栏目：写作、推荐、连载、活动、作品库等；
- 当前列表上下文；
- 当前文章 ID；
- 当前用户 ID；
- 右栏是否打开及当前面板；
- 左栏折叠和尺寸；
- 阅读页和评审页的局部分栏比例。

导航切换不应无故清除其他页面的数据。返回列表时尽量保留原来的排序、滚动、筛选和分页位置。

### 4.2 点击规则

- 点击文章卡片、文章标题或阅读入口：进入文章阅读页；
- 点击作者头像或作者名称：进入用户页；
- 点击评审摘要：进入对应文章，并打开评审面板；
- 点击评论摘要：进入对应文章，并定位到目标评论或评审评论；
- 点击用户卡：进入用户页；
- 点击通知：根据通知关联对象跳转到文章、评审、评论或用户页；
- 点击外部链接：交给系统默认浏览器，不在应用内加载未知远程页面。

### 4.3 启动页与用户页的区别

- 应用启动始终进入推荐首页；
- 用户卡是进入本人用户页的固定入口；
- 用户页返回后恢复进入用户页之前的页面；
- 文章作者、评审者、评论者头像都可以进入对应用户页。

## 5. 写作功能

### 5.1 写作入口

用户可以从以下位置进入写作：

- 左栏“写作”入口；
- 本地文件树中的 Markdown 文件；
- 写作首页的文章卡片；
- 远端文章的“转存为草稿”或“编辑”入口。

### 5.2 新建草稿

新建草稿时：

1. 用户点击新建；
2. 输入文件名并选择目录，或使用默认写作目录；
3. 应用创建一个纯空白 Markdown 文件；
4. 文件出现在本地文件树中；
5. 编辑器打开该文件。

新草稿不自动插入模板、标题、摘要或示例内容。

### 5.3 编辑器

编辑器提供两种模式：

- **可视化模式**：使用 Milkdown/ProseMirror 编辑 Markdown 内容；
- **源码模式**：使用 CodeMirror 直接编辑 Markdown 源文。

两种模式共享同一份文档内容，切换后不得丢失正文、frontmatter、公式和媒体标记。

编辑器支持：

- 标题、段落、列表、引用、代码等 Markdown 内容；
- 数学公式；
- 楷体等约定格式；
- 图片、音乐、视频等媒体；
- 自动保存；
- Ctrl+S 手动保存；
- 字数统计；
- 禁用词检查；
- 预览与目录生成。

### 5.4 自动保存与本地存档

编辑器变更后先写入本地 Markdown 文件。本地保存优先于网络同步：

- 网络不可用不影响本地写作；
- 保存失败时显示就地错误和重试按钮；
- 同步失败不回滚已经成功写入本地的正文；
- 关闭窗口前尽量完成待保存内容写入。

### 5.5 文件树

文件树只显示：

- Markdown 文件；
- 文件夹。

其他文件类型不作为文章节点展示，但可以继续存在于存档目录或媒体目录中。

文件树支持：

- 新建文件；
- 新建文件夹；
- 打开文件；
- 重命名文件或文件夹；
- 移动文件或文件夹；
- 删除本地文件或文件夹；
- 刷新索引。

文件树和写作首页卡片菜单都提供重命名与移动入口。

### 5.6 重命名与移动

重命名或移动文章时：

1. 用户从文件树右键菜单或写作首页卡片菜单发起操作；
2. 应用校验目标路径位于文档根目录内；
3. 检查目标名称是否为空、非法或与已有文件冲突；
4. 移动 Markdown 文件及其对应的 `.image` 目录；
5. 更新本地索引中的路径；
6. 保留远端文章 ID、四态和其他远端关联；
7. 刷新文件树与当前编辑器路径。

任何路径操作都必须经过 `resolve + realpath` 安全校验，拒绝路径穿越和符号链接逃逸。

### 5.7 本地删除

本地删除不影响远端文章：

1. 用户发起删除；
2. 应用显示二次确认；
3. 说明删除是本地删除，远端内容不会被删除；
4. 文件移动到系统回收站或应用约定的可恢复位置；
5. 删除本地索引记录；
6. 刷新文件树。

## 6. 同步、四态与发布

### 6.1 四种文章状态

本地文件可以与远端文章建立关联，并显示以下状态：

- **草稿**：文章仍处于可编辑草稿阶段；
- **待审核**：文章已发布，等待平台审核；
- **已发布**：远端文章已公开发布；
- **已拒绝**：远端审核未通过，可查看原因并继续本地编辑。

状态显示在左栏、写作首页卡片和文章索引中。

### 6.2 同步到草稿

同步到草稿流程：

1. 用户在编辑器中保存本地内容；
2. 点击“同步到草稿”；
3. 应用读取 Markdown、frontmatter 和媒体引用；
4. 上传或匹配媒体；
5. 调用远端草稿接口；
6. 更新本地远端关联和同步时间；
7. 显示成功或就地错误。

同步不会因为网络临时失败而清除本地内容。

### 6.3 冲突处理

当本地文件和远端内容都发生变化时，默认保护本地内容：

- 不自动用远端覆盖本地；
- 在冲突列表中显示冲突文章；
- 用户可以选择：
  - 覆盖远端：以本地内容推送；
  - 保留远端：拉取远端内容；
  - 另存副本：保存一份副本后再处理。

### 6.4 发布

发布表单规则：

- 文章类型必填；
- 活动默认不参加；
- 公开阅读默认开启；
- 发布前检查正文、类型、媒体和必要元数据；
- 发布成功后立即把本地状态标记为“待审核”。

审核结果由远端同步更新为“已发布”或“已拒绝”。客户端不自行虚构审核状态，无法确定时使用现有兜底文案。

### 6.5 远端文章转存

用户可以将远端文章转存为本地草稿：

1. 下载远端文章正文和媒体；
2. 转换为本地 Markdown；
3. 写入本地存档；
4. 建立或保留远端关联；
5. 在文件树和写作首页显示。

## 7. 阅读与浏览

### 7.1 栏目

应用提供以下主要栏目：

- **推荐**：推荐文章、最新评审、最新讨论、活动或模型入口等聚合内容；
- **连载**：连载或合集内容；
- **活动**：活动文章、活动状态和相关内容；
- **作品库**：按分类浏览文章，并提供最新讨论、最新评审信息流；
- **写作**：本地存档、远端四态和写作入口。

### 7.2 默认排序

- 推荐、连载、活动：时间降序；
- 作品库：评分降序；
- 科幻杂谈、官方公告、外文翻译等无评分分类：时间降序，并隐藏评分榜；
- 用户可以切换其他可用排序方式和升降序；
- 列表支持分页或无限滚动，正确处理无更多数据。

### 7.3 文章卡片

文章卡片统一展示：

- 封面和失败兜底；
- 标题、摘要；
- 作者和用户等级；
- 阅读、评论、点赞等统计；
- 评分、排名、并列名次；
- 待评审/已评审等状态徽章。

活动期或评审中的文章按活动规则隐藏评分、排名或作者信息，不泄露不应公开的内容。

### 7.4 阅读页

阅读页展示：

- 文章标题、作者、分类、时间和统计；
- 净化后的正文 HTML；
- 文章媒体；
- 目录；
- 评论；
- 评审；
- 收藏、点赞、投币等互动。

正文中的远程 HTML 必须经过白名单净化；媒体链接使用安全缓存协议；外部链接交系统浏览器处理。

阅读页右栏默认关闭。用户打开右栏后，可以在目录、评论、评审和搜索面板之间切换。

### 7.5 搜索

搜索分为两类：

1. **编辑器/阅读页 Ctrl+F**：覆盖正文，以及文章标题和摘要；编辑模式下支持替换；
2. **作品库首页全局搜索**：保留现有的评论、评审、用户搜索能力。

搜索加载失败时在当前面板显示错误与重试按钮，不弹出阻断式全局错误框。

## 8. 评审、评论与互动

### 8.1 评审面板

打开非本人文章后，评审面板默认显示“所有评审”。用户可以切换：

- 所有评审；
- 我的评审；
- 评审任务；
- 评审排序或筛选。

评审卡展示五维评分、评语、评审者、态度、评论数和关联内容。用户可以提交评审、编辑自己的评审、对评审表达态度。

平台没有返回明确审核状态时，客户端沿用现有兜底文案，不自行推断“已审核”或“未审核”。

### 8.2 评论

文章评论支持：

- 加载评论列表；
- 发表评论；
- 回复评论；
- 楼中楼；
- 引用父评论；
- 评审评论内嵌展示；
- 从评论摘要或通知定位到具体评论。

评论卡统一处理匿名作者、头像失败、回复入口和评论数量。

### 8.3 互动

保留现有互动能力：

- 点赞；
- 收藏；
- 投币；
- 关注/取关；
- 评审态度。

不新增独立的点赞榜、投币榜或其他未规划的个人资产页面；个人资产只保留现有“我的收藏”聚合。

## 9. 用户、通知与私聊

### 9.1 用户页

用户页可以从以下入口进入：

- 左栏用户卡；
- 文章作者头像或名称；
- 评审者头像；
- 评论者头像；
- 通知关联用户；
- 用户搜索结果。

用户页包含：

- 用户资料与等级；
- 动态；
- 收藏；
- 粉丝与关注；
- 文章；
- 评审；
- 评论；
- 关注/取关；
- 签到；
- 资料编辑；
- 私聊入口。

### 9.2 通知

通知中心提供：

- 未读数量；
- 未读红点；
- 评论、评审、财务、系统、粉丝、私聊等通知分类；
- 标记已读；
- 点击通知跳转到相关对象。

通知跳转目标缺失或内容已删除时，显示就地错误和返回/重试操作，不打开空白页面。

### 9.3 私聊

私聊流程：

1. 从用户卡或用户页进入私聊；
2. 打开会话列表；
3. 选择会话并加载消息；
4. 输入并发送消息；
5. 更新未读数和消息列表。

网络错误时保留已经输入但尚未发送的内容，显示重试入口。

## 10. 设置、更新与布局

### 10.1 设置分类

设置弹窗分为：

- **系统**：硬件加速、自动更新、缓存、卸载等；
- **界面**：主题、字体、缩放、自定义 CSS/JS；
- **用户**：账号相关和个人资料入口。

主进程设置通过 IPC 持久化；渲染层外观设置使用 localStorage 或统一 UI 设置存储。

### 10.2 布局持久化

以下布局状态需要在重启后恢复：

- 左栏是否折叠；
- 左栏宽度；
- 右栏是否打开；
- 右栏宽度；
- 评审页面左右分栏比例。

保存布局时要限制最小/最大宽度，防止窗口被设置为不可用尺寸。

### 10.3 更新

更新采用 GitHub Releases：

1. 客户端检查新版本；
2. 有新版本时显示横幅；
3. 用户主动点击下载；
4. 下载完成后提示安装；
5. 用户手动确认安装并重启。

不做静默自动安装，不做强制更新，不采集遥测或自动错误报告。

## 11. 加载、空态与错误反馈

### 11.1 加载态

- 首次加载使用与真实内容同构的骨架屏；
- 列表加载使用列表骨架屏；
- 阅读页、评论、评审分别显示局部加载状态；
- 已有内容刷新时尽量保留旧内容，避免整个页面闪空。

### 11.2 空态

空态使用简洁说明和明确行动按钮，例如：

- 没有本地文档 → “新建草稿”；
- 没有评论 → “发表第一条评论”；
- 没有评审 → “提交评审”；
- 没有通知 → “暂无通知”；
- 没有搜索结果 → 显示搜索范围和清除条件按钮。

### 11.3 错误态

错误优先在发生位置显示：

- 错误原因使用用户能理解的简短文案；
- 提供重试、重新加载、返回或重新登录按钮；
- 不使用阻断式全局错误弹窗承载普通网络错误；
- 启动配置、数据库、安全边界等无法继续运行的基础错误才使用启动错误提示并退出；
- 错误不应覆盖用户已经保存的本地内容。

---

## 12. 离线与网络异常

应用的离线优先级是本地写作，而不是完整离线内容库：

- 本地新建、编辑、保存、重命名、移动不依赖网络；
- 远端阅读内容按需拉取，不整站缓存；
- 同步、发布、评论、评审、通知和私聊失败时显示局部错误与重试；
- 不增加全局断网指示器；
- 网络异常不应被误判为登录失效；
- 只有服务端明确表示会话失效时才清除会话。

---

## 13. 安全与数据边界

- 渲染层启用 `contextIsolation`、`sandbox`，关闭 `nodeIntegration`；
- preload 只暴露明确的 `window.hqsf` 白名单 API；
- token 不进入渲染层、不进入普通日志；
- 所有文件路径必须限制在文档根目录；
- 远端 HTML 经过白名单净化；
- 图片使用缓存协议和安全 referrer 策略；
- 外部链接使用系统浏览器；
- 不采集遥测，不自动上报错误；
- 本地删除不联动远端；
- 退出登录不删除本地文档和索引。

---

## 14. 跨平台交互原则

Windows、Linux、macOS 具有同等优先级，但保留合理的平台差异：

- 窗口控件遵循平台习惯；
- 文件选择器、回收站、卸载入口使用平台能力；
- 快捷键在不同平台使用对应修饰键映射；
- 文件路径、图片缓存和数据库位置按平台规则处理；
- 核心产品行为、数据安全和页面功能保持一致。

## 15. 用户完整路径示例

### 15.1 新用户首次写作

```
启动 → 用户协议 → 推荐首页 → 写作 → 新建草稿
→ 空白编辑器 → 自动保存 → 文件树出现 Markdown 文件
```

### 15.2 发布文章

```
打开本地文章 → 编辑 → 保存 → 同步到草稿
→ 填写类型/活动/公开阅读 → 发布
→ 本地状态变为待审核 → 后续同步为已发布或已拒绝
```

### 15.3 阅读并评审

```
推荐/连载/活动/作品库 → 点击文章
→ 阅读正文 → 打开右栏 → 评审
→ 默认查看所有评审 → 提交五维评审 → 态度表态
→ 查看或回复评审评论
```

### 15.4 文件整理

```
文件树右键/写作首页卡片菜单 → 重命名或移动
→ 校验路径和冲突 → Markdown 与 .image 一起移动
→ 更新本地索引 → 保留远端关联 → 刷新界面
```

### 15.5 通知处理

```
未读红点 → 打开通知中心 → 点击通知
→ 跳转到文章/评审/评论/用户页
→ 执行查看、回复或标记已读
```

## 16. 功能边界总结

当前版本明确不做：

- AI 生成或 AI 管理能力；
- 版本管理；
- 账号注册、找回密码；
- 导入/导出；
- 自动备份；
- 完整离线内容库；
- 社区治理功能；
- 通知偏好设置；
- 新增点赞/投币资产页面；
- 遥测和自动错误上报。

当前版本的完成标准不是“功能越多越好”，而是稳定完成：

> 本地 Markdown 写作、可靠本地存档、远端同步发布、在线阅读、评审评论，以及围绕这些能力的用户和消息闭环。
